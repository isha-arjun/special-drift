## My Finance backup and restore notes

This repository also contains the product requirements for the My Finance dashboard's local encrypted backup workflow. The dashboard remains device-local: no cloud database, no server-side financial records, and no automatic backup upload.

See [docs/backup-restore-spec.md](docs/backup-restore-spec.md) for the encrypted export, Upload Backup, validation, and safe restore requirements.
